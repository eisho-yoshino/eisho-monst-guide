# 吉野瑛翔物語 — キャラ評価・攻略ガイド

HTML・CSS・JavaScriptだけで動く、オリジナルの静的攻略サイトです。外部API、画像、フォント、ライブラリ、ビルド処理、APIキーは不要です。

## 表示方法

`index.html` をブラウザで開いてください。ローカルサーバーを使う場合は、このディレクトリで次を実行します。

```sh
python3 -m http.server 8000
```

## 機能

- トップページと注目キャラ
- 全8キャラの図鑑、名前・よみがな検索、属性絞り込み、並び替え
- ハッシュURLから直接開けるキャラ詳細、能力、評価、編成のポイント
- 総合評価点のランキング（同点は同順位）
- 芳野中学校編・高岡高校編・横浜国立大学編の攻略とおすすめ編成
- スマホ対応、キーボード操作、検索件数の読み上げ

## データの編集

`characters.js` の `window.CHARACTERS` を編集します。`name`（名前）、`reading`（ひらがな）、`element`（属性）、`role`（役割）、`score`（10点満点）、`hp`、`attack`、`speed`、`ability`、`skill`、`description` などを変更できます。`id` は詳細URLで使用する一意な英数字にしてください。`color` はCSSの色、`icon` は文字のシンボルです。

攻略は同じファイルの `window.CHAPTERS` で編集します。`team` はキャラの `id` の配列、キャラの `chapter` は攻略の `name` と対応します。評価点を変更するとランキングに自動反映されます。

能力・評価点・攻略内容はすべて創作用の仮データで、実在の人物の能力や評価を示しません。公式画像やロゴは使用していません。

## GitHub Pagesで公開

1. 4つのサイトファイルを含む変更を `main` ブランチへコミット・プッシュします。
2. GitHubリポジトリの **Settings → Pages → Build and deployment** を開きます。
3. **Source: Deploy from a branch**、**Branch: main**、**Folder: / (root)** を選び、保存します。
4. GitHub側の公開処理が完了すると、Pages設定に公開URLが表示されます。

リンクとファイル参照は相対パス・ハッシュを使用するため、リポジトリ配下のGitHub Pagesでも動作します。公開設定の変更・プッシュは、この実装作業では実施していません。
